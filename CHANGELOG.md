# Changelog

All notable changes are documented here.

## [0.1.0] - 2026-08-21

### Added

- Deterministic AcroForm contract snapshots from canonical fields and page widgets.
- Semantic breaking-change, warning, and informational `ACR` rules.
- Explainable, advisory rename proposals and reviewed migration plans.
- Safe value migration with mapping, type, collision, required-field, and option validation.
- Fill/write/reopen verification for canonical values, widget values, and appearance streams.
- Synthetic versioned PDF fixtures, command-line demo, CI, and GitHub Release packaging.
